SimpleTools for Unity

More time for your game.

Animate objects. Paint and blend meshes. Connect online services.
Three focused packages for your Unity project.

SimpleTransform

Animate objects without writing movement scripts.

Build position, rotation, and scale sequences directly in Unity’s Scene view.

Useful forMoving platforms, object transitions, and looping scene motion.

What’s included

  • Position, rotation, and scale tracks
  • Bezier paths with draggable waypoint handles
  • 31 easing presets and per-channel timing
  • Looping, timed events, and rider-carrying platforms
Full capabilities ↗
Unity 2021.3+ · No dependencies · In development

SimpleBlend

Paint meshes and blend material layers in URP.

Use vertex colors as masks to add material variation to meshes, without changing imported source meshes.

Useful forBlending surfaces on level geometry, props, and skinned meshes.

What’s included

  • Scene-view vertex painting, without a collider
  • Paint, erase, smooth, fill, and sample brushes
  • Channel previews and composable masks
  • Three- and four-layer height-blend shaders
  • Per-renderer paint data; source meshes preserved
Full capabilities ↗Documentation ↗
URP only · 0.4.0-beta.1 · Vertex detail depends on mesh density

Supabase for Unity

Add accounts, online data, and backend services.

Connect a Unity game to a Supabase project through a C# SDK, with runtime APIs and editor setup tools.

Useful forPlayer accounts, leaderboards, shared game data, and uploaded files.

What’s included

  • Auth: sign-in, accounts, and sessions
  • Database: typed queries, filters, and CRUD
  • Realtime: database changes, broadcast, and presence
  • Storage: uploads, downloads, and signed URLs
  • Edge Functions and editor setup/model tools
Full capabilities ↗Documentation ↗
Unity 2021.3+ · Requires a Supabase project
